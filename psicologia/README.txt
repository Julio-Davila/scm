PLATAFORMA INTERACTIVA - ÁREA DE PSICOLOGÍA SCM

1. Abrir index.html en un navegador moderno (Chrome, Edge, Firefox, Safari).
2. Contraseña maestra: SCM2026
3. Completar las secciones y los tres juegos para alcanzar 100%.
4. Al 100% se habilita el diploma, que puede descargarse en PNG o imprimirse/guardarse como PDF.

IMPORTANTE SOBRE SEGURIDAD:
Esta versión es una aplicación web estática y funciona totalmente del lado del navegador. La contraseña no aparece en texto plano: se valida mediante SHA-256. Sin embargo, una aplicación estática no puede ofrecer control de acceso institucional verdaderamente robusto. Para producción se recomienda integrar autenticación en servidor (por ejemplo, Google Workspace/Microsoft Entra ID o un backend propio) y HTTPS.

CONTENIDO:
Basado en el PDF “Módulo 2 - Guía académica para el participante Relaciones Interpersonales”.

NUEVO EN V4 - GUARDADO AUTOMÁTICO:
- El nombre, correo, avance, módulos completados, juegos superados, tamaño de texto y última sección visitada se guardan automáticamente en localStorage del navegador.
- Cada correo docente mantiene su propio progreso en la misma PC y navegador.
- El botón “Salir” NO borra el avance; solo cierra la sesión visual de la plataforma.
- La barra derecha incluye un botón 💾 para forzar guardado y ↺ para reiniciar voluntariamente el progreso del docente actual.
- El avance puede perderse si se eliminan los datos/caché del navegador, se usa modo incógnito o se abre la plataforma en otra PC/navegador.
